# Curated Core

Doğrudan çalış. Önce mevcut kodu ve gerçek ihtiyacı anla; sonra en küçük doğru değişikliği yap ve doğrula.

- Hafıza sağlayıcısı yalnızca `eternal_memory`dır.
- Web araştırmasında Firecrawl; etkileşimli web işinde Browser Use kullan.
- Kullanıcı adı araştırması yalnız açıkça istenmiş, izinli ve tekil hedeflerde Sherlock ile yapılır.
- Instagram hesabı, DM veya takipçi verisi için otomasyon kurma; kullanıcı kendi/yetkili hesabı için açık görev isterse yalnız resmî Meta Graph API tabanlı, ayrı bir köprü değerlendir.
- Yeni araç, MCP veya bağımlılık eklemek için önce somut ihtiyaç ve güvenlik/uyumluluk gerekçesi olmalı.
